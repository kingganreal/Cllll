# 직캠 스테이지

직캠 영상에서 멤버 한 명만 배경 없이 따내서, 화면에 띄워 두고 보는 웹앱이에요.
폰, 태블릿, 데스크톱 브라우저에서 모두 돌아가고, 홈 화면에 앱처럼 설치할 수 있어요.

- **기기 안에서만 처리**: 영상은 서버로 올라가지 않아요. AI(MediaPipe Pose)가 브라우저 안에서 돌아요.
- **멤버 고르기**: 첫 장면에서 따낼 멤버를 탭하면, 영상 끝까지 그 사람을 따라가며 누끼를 따요. 다른 멤버는 빠져요.
- **무대**: 끌어서 옮기기, 두 손가락(또는 마우스 휠)으로 크기 조절, 좌우 반전, 속도, 여러 클립 동시에 띄우기,
  배경 바꾸기(그라데이션, 단색, 내 사진, 그린스크린), 전체화면과 화면 꺼짐 방지.
  데스크톱 Chrome/Edge에서는 **항상 위에** 버튼으로 다른 창 위에 작은 창으로 띄울 수 있어요.
- **소리**: 노래도 같이 저장돼요. 무대에서 클립을 탭하고 "소리 켜기"를 누르세요.
- **기기 간 옮기기**: 보관함에서 "저장"을 누르면 `.stage-sbs.mp4` 파일이 생겨요. 다른 기기에서 "파일 가져오기"로 열면 돼요.

## 유튜브 링크로 가져오기

브라우저는 유튜브 영상을 직접 내려받을 수 없어서, **재생되는 화면을 녹화하는 방식**으로 가져와요.
"만들기" 화면의 "유튜브 링크로 가져오기"에 링크를 붙여 넣으면 기기에 맞는 안내가 나와요.

- **PC (Chrome / Edge)**: 앱이 유튜브 탭을 바로 녹화해요. 유튜브 탭을 연 다음 "녹화 시작"을 누르고, 그 탭을 고르고
  "탭 오디오도 공유"를 켜세요. 그다음 유튜브에서 전체화면(F 키)으로 재생하고, 다 보면 "녹화 끝"을 누르세요.
- **폰 / 태블릿**: 기기의 화면 녹화(iPhone 제어 센터의 화면 기록, 안드로이드 빠른 설정의 화면 녹화)로 전체화면 재생을
  녹화한 뒤, 녹화 파일을 "직캠 영상 고르기"로 불러오세요.

녹화본이나 화면 녹화 파일에 생긴 **검은 테두리는 자동으로 잘라 내요**. 필요 없으면 체크를 끄면 돼요.
녹화는 실시간이라 영상 길이만큼 걸리고, 화질은 유튜브에서 재생한 화질을 따라가요.

## 윈도우 앱: 바탕화면에 띄우기

[Releases](https://github.com/kingganreal/Cllll/releases/latest)에서 `FancamStage-Setup-….exe`를 받아 설치하세요
("Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행). 설치하면 작업 표시줄 오른쪽 트레이에서 조용히 돌아가요.

- 크롬에서 웹앱을 열고 클립의 **바탕화면에**를 누르면, 그 클립이 바탕화면에 배경 없이 떠요. 무대 화면에서도 돼요.
- 캐릭터는 끌어서 옮기고, 마우스 휠로 크기를 바꿔요. 캐릭터가 없는 투명한 부분은 클릭이 뒤로 통과해요.
- **오른쪽 클릭**: 좌우 반전, 소리, 속도, 크기, 투명도, 항상 위에, 하나 더 띄우기, 내리기.
- 띄워 둔 캐릭터는 PC를 다시 켜도 그 자리에 다시 떠요. "윈도우를 켜면 자동으로 실행"을 켜 두면 편해요.
- 앱이 켜져 있으면 웹앱의 유튜브 원본 받기가 바로 돼요. 따로 도우미를 켤 필요가 없어요.

앱 코드는 `desktop/`에 있어요 (Electron). `desktop/` 또는 `js/player.js`가 바뀌면 GitHub Actions가 윈도우 설치 파일을 만들어
Releases에 올려요. 새 버전을 내려면 `desktop/package.json`의 `version`을 올리세요.

### 윈도우 PC: 4K 원본 받기 (추천)

윈도우 앱이 켜져 있으면 아래 과정 없이 바로 돼요. 앱을 설치하기 싫을 때는 도우미 스크립트만 써도 돼요.

윈도우 PC의 Chrome이나 Edge에서 유튜브 링크를 넣으면 **PC 도우미**로 원본 파일(최대 4K)을 바로 받을 수 있어요.

1. 링크를 넣고 "가져오기"를 누른 뒤 **FancamStage-Helper.bat 받기**를 눌러요.
2. 받은 파일을 더블클릭해요. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요.
   처음 실행할 때 yt-dlp, ffmpeg, deno(200MB 정도)를 `%LOCALAPPDATA%\FancamStage`에 받아요.
3. 검은 창에 "준비 완료"가 뜨면 앱 화면이 바뀌어요. **원본 받기**를 누르면 받아서 바로 편집 화면에 띄워요.
   4K 원본이면 화질이 자동으로 "FHD · 4K 원본용"으로 맞춰져요.
4. 만든 클립은 구글 드라이브 동기화로 폰과 패드에 넘어가요.

도우미는 `http://localhost:8790`에서만 열리고, 이 앱 사이트에서 온 요청만 받아요. 실행할 때마다 yt-dlp를 최신으로 업데이트해요.
브라우저가 "로컬 네트워크 접근"을 물어보면 허용해 주세요.
유튜브 이용약관은 유튜브가 제공하는 기능 밖의 다운로드를 금지하고 있어요. 개인 감상용으로만 써 주세요.

**4K 화질로 하고 싶으면** 녹화 대신 원본 영상 파일을 PC에 받아서 "직캠 영상 고르기"로 넣고, 화질을 **FHD · 4K 원본용**으로 고르세요.
결과물은 반쪽당 1080×1920(풀HD)으로 저장돼요. 4K 원본에서 줄여 만들어서 녹화본보다 훨씬 선명해요.
폰과 패드가 재생할 수 있는 크기는 이 정도가 한계라 4K 그대로 저장하지는 않아요.
유튜브 4K는 VP9/AV1 WebM으로 오는 경우가 많아서, 처리는 PC의 Chrome이나 Edge에서 하는 게 안전해요.
만든 클립은 H.264 MP4라서 동기화하면 폰과 패드에서도 그대로 재생돼요.

## 폰 · 패드 · 컴퓨터 동기화 (구글 드라이브)

클립을 내 구글 드라이브의 **직캠 스테이지** 폴더에 올려 두고, 연결된 모든 기기가 같은 클립을 보게 해요.
만들기, 이름 바꾸기, 삭제가 다른 기기에도 반영돼요. 무대 배치는 화면 크기가 달라서 기기마다 따로 저장돼요.
앱은 `drive.file` 권한만 써서, 자기가 만든 파일 말고는 드라이브의 다른 파일을 볼 수 없어요.

### 처음 한 번: 구글에 앱 등록하기 (10분 정도)

1. [구글 클라우드 콘솔](https://console.cloud.google.com/projectcreate)에서 프로젝트를 만들어요 (예: `fancam-stage`).
2. [Google Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com)에서 **사용**을 눌러요.
3. [Google 인증 플랫폼](https://console.cloud.google.com/auth/overview)에서 시작하기 → 앱 이름, 지원 이메일, 대상 **외부**, 연락처 이메일 → 만들기.
4. **대상** 메뉴 → 테스트 사용자에 내 지메일 주소를 추가해요.
5. **클라이언트** 메뉴 → 클라이언트 만들기 → **웹 애플리케이션** → 승인된 자바스크립트 원본에 앱 주소
   (예: `https://kingganreal.github.io`)를 넣고 만들기.
6. 앱의 **기기 동기화**에 클라이언트 ID(`….apps.googleusercontent.com`)를 붙여 넣고 로그인해요.
   "Google에서 확인하지 않은 앱" 화면이 나오면 계속을 누르고, 드라이브 접근 체크 상자를 켜 주세요.

다른 기기는 **다른 기기 연결 링크 복사**로 만든 링크를 열고 로그인만 하면 돼요.
클라이언트 ID를 `js/config.js`에 넣어 두면 링크 없이 로그인만으로 연결돼요.

- 구글 로그인은 보안상 한 시간쯤 지나면 다시 확인해요. 그때는 보관함 위에 뜨는 **구글 드라이브와 동기화하기**를 한 번 누르면 돼요.
- 지운 클립은 드라이브 휴지통으로 가서 30일 동안 되살릴 수 있어요.
- 예전에 GitHub 동기화를 썼다면, 처음 드라이브에 연결할 때 GitHub에만 있던 클립을 자동으로 옮겨 와요.

## 쓰는 법

1. **직캠 영상에서 만들기** → 영상 고르기
2. 필요하면 구간(시작/끝) 정하기. 시작 장면에 멤버가 잘 보여야 해요.
3. **멤버 고르기** → 분홍색으로 표시된 사람이 맞는지 확인하고, 아니면 원하는 멤버를 탭
4. **이 멤버로 추출 시작**. 처리하는 동안 화면을 켜 둔 채 기다려 주세요.
5. 끝나면 무대에 바로 올라가요.

처리는 프레임마다 AI를 돌려서 영상 길이보다 오래 걸릴 수 있어요(기기 성능에 따라 차이가 커요).

- **GPU 고급 누끼**: WebGPU가 되는 브라우저(PC의 Chrome·Edge, 최신 Safari)에서는 영상용 누끼 모델(RVM)로
  머리카락·손끝·치마 같은 테두리를 깔끔하게 따요. 처음 한 번 모델(약 40MB)을 받아요. 안 되는 기기에서는 기본 누끼로 해요.
- 멤버끼리 겹칠 때는 그 멤버의 뼈대(관절 위치) 주변만 남겨서 다른 멤버가 섞이지 않게 해요.
  잠깐 가려져서 못 찾으면 1초까지는 그 자리를 유지하고, 다시 찾을 때는 옷 색과 화면 중앙을 보고 찾아요.
급하면 화질 "보통", 프레임 "24fps"로 하거나 구간을 짧게 잘라 주세요.

## 실행하기

정적 파일만 있어서 아무 웹서버에 올리면 돼요. (`file://`로 직접 열면 안 돼요.)

- **GitHub Pages**: 저장소 Settings → Pages → Source를 "GitHub Actions"로 바꾸면
  `.github/workflows/pages.yml`이 자동으로 배포해요. 나온 주소를 폰에서 열고 "홈 화면에 추가"하세요.
- **내 PC에서**: `npx http-server .` 후 `http://localhost:8080` 접속.
  같은 와이파이의 폰에서 열려면 HTTPS가 필요해서 Pages 쪽이 편해요.

## 구조

```
index.html          화면 (보관함 / 만들기 / 무대)
js/processor.js     추출: 사람 찾기 → 대상 추적(겹침·옷 색·움직임·화면 중앙) → 누끼 → 인코딩
js/source.js        영상을 처음부터 순서대로 디코딩 (web-demuxer + WebCodecs, 안 되면 탐색 방식)
js/matting.js       GPU 고급 누끼 (RVM, onnxruntime-web WebGPU)
js/player.js        재생: 색|투명도로 나란히 담긴 MP4를 WebGL로 합쳐 투명하게 그리기
js/store.js         IndexedDB 저장
js/drive.js         구글 드라이브로 기기 간 동기화
js/config.js        구글 클라이언트 ID 설정
js/sync.js          예전 GitHub 동기화 (드라이브로 옮길 때만 사용)
js/helper.js        윈도우 PC 도우미와 통신
helper/             윈도우 PC 도우미 (PowerShell, 앱 없이 쓸 때)
desktop/            윈도우 앱 (Electron: 바탕화면 오버레이, 유튜브 받기)
js/app.js           UI, 무대 조작
sw.js               오프라인 캐시
vendor/, models/    MediaPipe tasks-vision 1.0.1, mp4-muxer 5.2.2, web-demuxer 4.0.0, onnxruntime-web 1.30.0,
                    pose_landmarker_full, RVM mobilenetv3 (GPL-3.0, models/RVM-LICENSE.txt;
                    WebGPU에서 정확히 돌도록 일부 합성곱 입력을 0 채널로 채우고 AveragePool ceil_mode를 끈 수정본)
```

투명 영상을 모든 기기에서 재생하려고, 결과물은 한 프레임에 **색(왼쪽)과 투명도(오른쪽)**를 나란히 담은
일반 MP4(H.264)로 저장해요. 무대에서 셰이더가 둘을 합쳐 배경을 투명하게 만들어요.

직캠 영상의 저작권은 원저작자에게 있어요. 개인 감상용으로 써 주세요.
