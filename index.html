기기 동기화

폰, 패드, 컴퓨터가 같은 클립을 보도록 내 GitHub의 비공개 저장소에 클립을 올려 둬요. 처음 한 번만 설정하면 돼요.

  1. 비공개 저장소 만들기 여기를 열고 Private인지 확인한 뒤 Create repository를 누르세요.
  2. 토큰 만들기 여기에서 Repository access를 Only select repositories → fancam-clips로 고르고, Permissions의 Contents를 Read and write로 바꾼 뒤 Generate token. 나온 토큰을 복사하세요.
  3. 아래에 붙여 넣고 연결. 다른 기기는 연결된 기기에서 만든 링크만 열면 돼요.

에 연결됐어요. 클립을 만들거나 지우면 다른 기기에도 똑같이 반영돼요.

연결 링크에는 토큰이 들어 있어요. 카카오톡 나와의 채팅처럼 나만 보는 곳으로 보내서, 그 기기에서 열면 바로 연결돼요. 저장소에 클립 1개당 보통 수십 MB가 쌓여요. 지운 클립도 GitHub 기록에는 남아서 용량이 줄지는 않아요.

내 클립

  1. 직캠 영상 고르기 갤러리나 파일에서 영상을 불러와요. 영상은 기기 밖으로 나가지 않아요.
  2. 멤버 탭하기 첫 장면에서 따낼 멤버를 고르면 끝까지 따라가며 누끼를 따요.
  3. 무대에 띄우기 끌어서 옮기고, 두 손가락으로 크기를 바꾸고, 전체화면으로 띄워 두세요.
