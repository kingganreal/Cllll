직캠 스테이지

구글 드라이브 동기화

폰, 패드, 컴퓨터가 같은 클립을 보도록 내 구글 드라이브의 "직캠 스테이지" 폴더에 클립을 올려 둬요. 앱은 자기가 만든 파일만 볼 수 있어요. 처음 한 번, 구글에 이 앱을 등록해야 해요 (10분 정도).

  1. 프로젝트 만들기 구글 클라우드 콘솔에서 프로젝트 이름을 fancam-stage로 정하고 만들기.
  2. 드라이브 API 켜기 Google Drive API에서 사용을 누르세요.
  3. 앱 정보 등록 Google 인증 플랫폼에서 시작하기 → 앱 이름 직캠 스테이지, 지원 이메일은 내 메일, 대상은 외부, 연락처 이메일 입력 → 만들기.
  4. 나를 테스트 사용자로 추가 왼쪽 메뉴 대상 → 테스트 사용자 → Add users → 내 지메일 주소.
  5. 클라이언트 만들기 왼쪽 메뉴 클라이언트 → 클라이언트 만들기 → 유형 웹 애플리케이션 → 승인된 자바스크립트 원본에 아래 주소 추가 → 만들기.
  6. 클라이언트 ID 붙여 넣기 만들어진 …apps.googleusercontent.com로 끝나는 ID를 아래에 넣으세요.

구글로 로그인하면 이 기기의 클립이 드라이브에 올라가고, 다른 기기에서 만든 클립을 받아 와요. 처음 로그인할 때 "Google에서 확인하지 않은 앱" 화면이 나오면 계속을 누르고, 드라이브 접근 체크 상자를 켜 주세요.

구글 드라이브의 직캠 스테이지 폴더와 동기화하고 있어요. 클립을 만들거나 이름을 바꾸거나 지우면 다른 기기에도 반영돼요.

다른 기기에서는 이 앱을 열고 "기기 동기화" → 구글로 로그인만 하면 돼요. 클라이언트 ID를 다시 넣기 귀찮으면 연결 링크를 보내서 여세요. 지운 클립은 드라이브 휴지통으로 가서 30일 동안 되살릴 수 있어요. 구글은 보안상 한 시간쯤 지나면 로그인을 다시 확인해요. 그때는 위에 뜨는 버튼을 한 번 눌러 주세요.

내 클립

  1. 직캠 영상 고르기 갤러리나 파일에서 영상을 불러와요. 영상은 기기 밖으로 나가지 않아요.
  2. 멤버 탭하기 첫 장면에서 따낼 멤버를 고르면 끝까지 따라가며 누끼를 따요.
  3. 무대에 띄우기 끌어서 옮기고, 두 손가락으로 크기를 바꾸고, 전체화면으로 띄워 두세요.
